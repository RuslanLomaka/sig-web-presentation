# Вебпрезентація Smart Industry Group

Відкрийте `dist/index.html` у настільному браузері. Сторінка працює офлайн на HTML, CSS і JavaScript. Для запуску достатньо всієї папки `dist`.

Демонстрація охоплює зупинку лінії, аналіз трендів, зміну порога, стабільний режим та передачу зміни. Дані, події та відповіді асистента є умовними.

- `dist/index.html` містить сторінку й тексти.
- `dist/styles.css` містить стилі та підключення локальних шрифтів.
- `dist/demo.js` містить сценарії, перемикачі та графіки.
